# AI-safety
Aim to train a small neural network. The first section uses make_moons to generate data.

1. Single Neuron (build by hand): Classify using a single neuron. The training accuracy is 87.25% and the test accuracy is 85.00%. Add cubic features and the test accuracy reaches 95.00%.
2. Two Layer Neuron (build by hand): Classify using a two-layer neuron with 10 neurons in the hidden layer. The training accuracy is 97.75% and the test accuracy is 97%.
3. Two Layer for Micrograd: Build on Micrograd (https://github.com/karpathy/micrograd). The training accuracy is 97.5%, and test accuracy is 96.0%.
4. Two Layer in Pytorch: Classify using a two-layer neuron with 10 neurons in the hidden layer. The training accuracy is 98% and the test accuracy is 97%.

The second section uses MNIST.

AI (Claude) is used to aid learning. All code are manually verified.
